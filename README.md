# Book Nest

Book Nest is a simple Library Management System developed using Java.

This project is based on Java Object-Oriented Programming (OOP) concepts.

Users can create an account and login to the system.

The system allows users to add, show, search, update, and delete books.

Users can also borrow and return books.

The system includes a Purchase Book option.

Purchase information is saved using file handling and Java Serialization.

This project was developed as a university group project.

It helped us practice Java OOP, file handling, and GitHub collaboration.
